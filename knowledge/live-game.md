# Live-игры

Live-состояние проверяй непосредственно перед записью. Считай игроками на уровне элементы `current_players`, а уже затронутыми уровнем — `passed_players`.

## Матрица решений

| Операция | Состояние | Действие |
|---|---|---|
| Добавить alias правильного ответа | Любое | Можно применить по явной просьбе; не заменяй работающий код. |
| Изменить задание, уже показанное игрокам | Есть current или passed | Предупреди о неравенстве условий и запроси подтверждение; предложи сообщение организатора. |
| Изменить время подсказки | Никто не достиг уровня | Можно применить без дополнительного подтверждения. |
| Изменить время подсказки | Есть current | Покажи старое/новое время и запроси подтверждение. |
| Изменить время подсказки | Есть passed | Предупреди о разных условиях команд и запроси подтверждение. |
| Удалить сектор (modern) | Есть current или live state неизвестен | Не выполняй. Добавление ответа или сообщение обычно безопаснее. |
| Удалить сектор (modern) | Нет current | Создай snapshot и запроси подтверждение; удаляются связанные ответы. |
| Удалить сектор (native legacy) | Любое, включая current и неизвестное состояние | Покажи snapshot точного сектора и связанных кодов, сообщи известное состояние игроков или его неизвестность и запроси подтверждение именно этого удаления. После подтверждения выполни удаление и read-back. |
| Снять/вернуть уровень | Любое | Создай snapshot и запроси подтверждение. |
| Массовая или необратимая операция | Любое | Snapshot, точный список целей и подтверждение. |

Если live state недоступен, не интерпретируй это как «игроков нет». Для изменения задания/подсказки/кода потребуй подтверждение неизвестного риска; удаление modern-сектора блокируй до получения состояния. Для native legacy применяй отдельную строку матрицы: неизвестное состояние явно показывается при подтверждении и не заменяется вымышленным отсутствием игроков.

## Инциденты

- Ошибка в коде: добавь правильный alias, сохрани опубликованный код и проверь оба варианта.
- Ошибка в задании: если команды уже видели текст, сообщение организатора часто честнее тихой замены.
- Критический дефект уровня: снятие допустимо только после snapshot и подтверждения.
- Пересчёт/снятие не выбирай по текущему месту команды в таблице.

В отчёте укажи время preflight, число current/passed и то, какое правило матрицы сработало.

Эта матрица описывает preflight локального MCP runtime. Ограничения установленного adapter и сервера остаются обязательными; матрица не разрешает обходить version/apply-контракт.
