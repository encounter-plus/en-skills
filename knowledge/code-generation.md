# Генерация кодов

Когда автор просит сгенерировать коды, используйте инструменты локального генератора, если они предоставлены хостом. Не выдавайте придуманные моделью слова или цифры за результат случайной генерации. Сам скилл инструмент не устанавливает.

Реализация и схемы инструментов находятся в `src/code-generator.ts` пакета en-skills, публичный импорт — `@encounter-author/tools/code-generator`. `createCodeGeneratorTools(loadDictionary, random?)` принимает загрузчик словаря от хоста; без него доступны буквенные и цифровые коды, а генерация слов сообщает об отсутствии загрузчика. Алгоритмы в хосте не дублируются.

## Три режима

- generate_word_codes: существительное из локальной категории nouns/ru CityProject + числовой античит. minLength/maxLength включительны, относятся только к буквам слова, без античита, дефисов и апострофов. Без параметров диапазон 1–100 покрывает словарь. excludeLetters — буквальная строка русских букв, например ЩЪ; регистр неважен, ё и е различаются. По умолчанию исключённых букв нет.
- generate_letter_codes: случайная последовательность букв + античит. length — число букв, по умолчанию 6. alphabet по умолчанию содержит все 33 русские строчные буквы, включая ё/ъ/ь/щ. Можно явно задать набор русских/латинских букв; регистр сохраняется, повторы символов в алфавите не увеличивают вероятность.
- generate_digit_codes: строка случайных цифр заданной length (по умолчанию 6); ведущие нули сохраняются. Дополнительного античита нет.

count по умолчанию 10, допустимо 1–100 результатов за вызов. Для букв/цифр length 1–32. Словарь не передаётся модели целиком; инструмент возвращает выбранные результаты и применённые ограничения.

## Античит

`antiMode: "random"` (по умолчанию) выбирает античит независимо для каждой основы в диапазоне `antiMin..antiMax`; числа могут повторяться. Для «по одному от 1 до 24» используйте `antiMode: "sequential", count: 24, antiMin: 1, antiMax: 24`: слова выбираются случайно, а суффиксы назначаются по порядку без повторов. Если количество больше размера диапазона, инструмент должен вернуть ошибку, а не начать нумерацию заново. Простой диапазон 1–24 без sequential не гарантирует полный набор.

`antiWidth` задаёт минимальную ширину суффикса: default 2 сохраняет `01..09`; явное `antiWidth: 1` даёт `1..9`. Для запроса «24 слова длиной 4–5 с античитами 1–24» используйте `generate_word_codes` с `count: 24, minLength: 4, maxLength: 5, antiMode: "sequential", antiMin: 1, antiMax: 24, antiWidth: 1`. Случайные античиты 10–99 или 100–999 задаются `antiMode: "random"` с соответствующими включительными границами. Если установленный tool ещё не поддерживает эти параметры, обновите host или сообщите о несовместимости; не подменяйте выданные суффиксы молча.

В словах и буквенных последовательностях antiMin/antiMax задают включительный диапазон. По умолчанию 10–99. При стандартной ширине 2 диапазон 1–9 записывается как 01…09. Для постоянного значения 8 задайте обе границы 8: суффикс 08. Ноль записывается 00. Значения от 10 записываются без дополнительного нуля, если автор не увеличил antiWidth. Верхняя допустимая граница 999999.

Это дополнительная часть кода, не префикс игры и не отдельный код доезда. При объединении нет разделителя: мост + 08 → мост08. Сохраняйте base, antiCheat и итоговую строку code буквально. Ни код, ни античит не преобразуйте в число при переносе в таблицу/движок.

## Проверка результата

Покажите количество, длину, исключения/алфавит и диапазон античита вместе со списком кодов. Ограничения автора важнее defaults. Если исходных вариантов недостаточно, сообщите число доступных и предложите изменить параметры; не ослабляйте их молча.

Уникальность гарантируется для основ только внутри одной выдачи; случайные античиты могут повторяться, последовательные — нет. Между вызовами и относительно существующей игры уникальность не гарантируется. Для проверки существующих ответов используйте доступное локальное сравнение по API, а не отправку кодов в движок. Словарь может включать редкие и неподходящие автору слова: результат — кандидаты для просмотра, не гарантия простоты написания. Самостоятельно не вводите скрытых исключений букв или слов.

Генерация не меняет игру и разрешена в read-only. Добавление выбранных ответов — отдельное действие через реально доступные инструменты и режим доступа хоста.
