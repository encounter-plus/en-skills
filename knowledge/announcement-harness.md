# Локальный мок страницы игры для анонсов

## Запуск

```powershell
node harness/announcement/run.mjs --channel chrome
node harness/announcement/run.mjs --channel chrome --html "./announcement.html" --assets "./assets" --scenario "./announcement-scenario.json" --out "./artifacts/announcement"
node harness/announcement/run.mjs --serve --html "./announcement.html" --assets "./assets"
# После установки npm-пакета:
en-announcement-check --channel chrome --html "./announcement.html" --scenario "./announcement-scenario.json"
```

`--serve` печатает локальный адрес и работает до Ctrl+C. Для ручной проверки меняйте ширину окна. `--channel chrome` использует установленный Chrome; без параметра нужен установленный Playwright Chromium. `--headed` показывает окно автоматического прогона.

В `--html` передавайте HTML-фрагмент анонса, без собственной оболочки html/head/body. Ресурсы из явно выбранной `--assets` папки доступны как `/author-assets/имя`; например `/author-assets/poster.png`. Внешние ссылки разрешены как содержимое, но автоматическое посещение внешних адресов блокируется. Для проверки ссылки проверяйте её адрес, а переход на реальный сайт делайте отдельно.

Без аргументов выполняется встроенный синтетический пример. С пользовательским `--html`, но без `--scenario`, проверяются только загрузка и компоновка; это отражается в отчёте и не считается проверкой всех действий.

## Сценарий

```json
{"steps":[{"click":"#show-kit","expectText":{"selector":"#kit-result","text":"Фонарик и удобная обувь"}}]}
```

Поддержаны `click` (на mobile — tap), `fill: {selector, value}`, `press: {selector, key}`, `expectText: {selector, text}` и `expectVisible` (селектор). В одном шаге сначала выполняются fill/click/press, затем ожидания. Для клавиатуры добавьте отдельный шаг `press`, например Enter на кнопке. Создавайте сценарий под конкретную механику автора.

## Результаты и ограничения

Профили: desktop 1280×900 и mobile 390×844 с касанием. На каждый сохраняются PNG до/после, trace.zip и результат в report.json. Проверяются сценарий, ошибки JS, нарушения локальной CSP, неуспешная загрузка ресурсов, битые картинки и горизонтальное переполнение страницы/контейнера. Ошибка даёт exit 1.

Сеть ограничена локальным сервером. Мок не поддерживает авторизацию, реальные API-запросы, iframe и серверные формы. CSP — политика стенда, а не копия сайта. Авторский JS выполняется как обычный браузерный скрипт: серверная очистка HTML и механизм исполнения скриптов живой страницы не эмулируются. Зеленый тест не подтверждает, что сайт сохранит и исполнит те же теги.

Стенд проверяет страницу игры в Chromium. Он не проверяет Android WebView, превью sharing, все размеры карточек и фактическое назначение poster_url. Для постера отдельно примените [чеклист превью](announcement-workflow.md).
