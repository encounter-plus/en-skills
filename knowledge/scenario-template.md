# Шаблон документа для переноса сценария

Скопируйте разделы в Google Docs либо сделайте из них листы Google Sheets. Имена колонок и число листов можно менять; смысл полей и связи должны оставаться явными. Это авторский шаблон, не схема API. Правила заполнения и необходимые уточнения описаны в [памятке автору](scenario-authoring.md).

## 00. Как читать / паспорт

| Поле | Заполнить |
|---|---|
| Название и актуальная версия | … |
| Целевая игра | Ссылка на редактор игры |
| Объём текущего переноса | Какие уровни и общие объекты переносить; что отложено |
| Общие настройки | Область применения, значения, единицы; ссылки на исключения |
| Статусы блоков | Актуально / черновик / устарело / отменено |
| Назначения | Задание / ответ / подсказка / бонус / Help / оформление / служебное |
| Нерешённые вопросы | Решение, к какому объекту относится, кто его принимает |

Заполнитель `…` означает «ещё не заполнено». Он не означает пустой текст или нулевую награду. Рабочие обозначения ниже — синтетический пример; замените их своими. Не вставляйте в игру демонстрационные тексты и коды.

## 01. Порядок уровней

| Порядок в игре | Обозначение | Номер в документе | Тип | Название | Ссылка на материал |
|---|---|---|---|---|---|
| 1 | БР | 0 | Брифинг | … | … |
| 2 | ИНФ01 | — | Информационный уровень | … | … |
| 3 | Э01 | 1 | Игровой | … | … |
| 4 | Э02 | 2 | Игровой | … | … |

Продолжите таблицу до последнего этапа, включая переходы и остальные этапы серии. Номер в документе и порядок в движке могут отличаться.

## 02. Карточка уровня — повторить для каждого этапа

| Поле | Заполнить |
|---|---|
| Обозначение и название | … |
| Статус | … |
| Полный текст игрокам | Готовый текст либо явное поручение создать его с ограничениями |
| Формат ответа (ФО) | … |
| Завершение | Например: один сектор, любой его ответ; либо 3 закрытых сектора из 4; для организационного уровня — его конкретное условие |
| Автопереход | Выключен либо длительность с единицей и точкой отсчёта |
| Штраф за автопереход | Число и единица либо ссылка на общий профиль |
| Связанные объекты | Обозначения секторов, подсказок, бонусов и файлов |
| Ограничения / особая механика | Готовое правило либо «нет» |
| Разгадка для автора | Отдельный служебный текст, не переносить |

## 03. Секторы и ответы

| Уровень | Обозначение сектора | Название в движке | Правило зачёта |
|---|---|---|---|
| Э01 | Э01-С01 | Ответ | Любой допустимый ответ этого сектора |

Для каждого варианта — отдельная строка. Формат ячеек с ответами: текст.

| Объект ответа | Допустимый ответ | Статус |
|---|---|---|
| Э01-С01 | пример01 | Актуально |
| Э01-С01 | вариант01 | Актуально |

Эти две строки демонстрируют альтернативы одного сектора, а не два обязательных кода. Если нужно несколько обязательных секторов, заведите отдельные обозначения и задайте порог в карточке уровня.

## 04. Подсказки

| Уровень | Обозначение | Вид | Время появления | Отсчёт от | Текст игрокам | Штраф за взятие | Статус переноса |
|---|---|---|---|---|---|---|---|
| Э01 | Э01-П01 | Обычная | 5 минут | Старта Э01 | … | Не применимо | Переносить |
| Э01 | Э01-П02 | Штрафная | … | … | … | … | … |

Для обычной подсказки штраф за взятие не применяется. «Не переносить сейчас» сохраняет и текст, и время в документе.

## 05. Бонусы

| Обозначение | Название в движке | Текст до выполнения | Help после выполнения | Награда / штраф | Доступность |
|---|---|---|---|---|---|
| ОБ01 | 2.3 | Пустой текст | Имя персонажа: … | 0 секунд, награды нет | Сразу при доступе к применимому уровню; без дополнительного окна |

| Объект ответа | Допустимый ответ |
|---|---|
| ОБ01 | пример42 |

| Объект | Область действия | Один общий объект или копии | Получатель |
|---|---|---|---|
| ОБ01 | Э01, Э02 | Один общий бонус | Все команды |

Записывайте `2.3` как текст. Если уровней шесть, перечислите все шесть обозначений; для всей игры напишите «все уровни игры». Если Help должен содержать только имя персонажа, удалите демонстрационную подпись «Имя персонажа:».

## 06. Оформление, файлы и сообщения организатора

| Уровень / место использования | Порядок блока | Назначение | Точный текст |
|---|---|---|---|
| ИНФ01 | 1 | Заголовок | … |
| ИНФ01 | 2 | Основной текст | … |

| Ресурс | Источник или поручение | Куда загрузить | Как подключить | Где использовать |
|---|---|---|---|---|
| game-style.css | Ссылка на готовый CSS либо задание создать стиль | Файлы игры | Подключение CSS в HTML сообщения ОРГ01 | Классы в разметке блоков ИНФ01 |

| Сообщение | Назначение и текст/HTML | Область действия |
|---|---|---|
| ОРГ01 | Подключить загруженный game-style.css; при наличии — точный HTML | Все уровни игры |

У каждого изображения укажите назначение: текст задания, подсказка, Help либо служебная фотография отписки. Для фото кода свяжите файл с уровнем и объектом ответа, отдельно сохраните физическую надпись и вводимый ответ.
