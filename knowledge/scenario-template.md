# Шаблон документа для переноса сценария

Для нового общего документа используйте структуру ниже по [процессу совместной работы](shared-game-document.md). Если автор уже ведёт документ, сверяйте по шаблону полноту и дополняйте его разделы по месту. Заполняйте поля по мере разработки. Значения и назначение блоков трактуйте по [памятке автору](scenario-authoring.md).

## Общее

### Паспорт игры

| Поле | Заполнить |
|---|---|
| Название и актуальная версия | … |
| Автор по умолчанию | … |
| Замысел и ограничения | … |
| Целевая игра | Ссылка на редактор игры |
| Объём текущего переноса | Какие уровни и общие объекты переносить; что отложено |
| Общие настройки | Область применения, значения, единицы; ссылки на исключения |
| Статусы блоков | Актуально / черновик / устарело / отменено |
| Назначения | Задание / ответ / подсказка / бонус / Help / оформление / служебное |
| Нерешённые вопросы | Решение, к какому объекту относится, кто его принимает |

Заполнитель `…` означает «ещё не заполнено». Он не означает пустой текст или нулевую награду. Рабочие обозначения ниже — синтетический пример; замените их своими. Не вставляйте в игру демонстрационные тексты и коды.

## 02. Карточка уровня — повторить для каждого этапа

Для каждого уровня используйте один лист. Таблицы секторов, подсказок, бонусов и оформления ниже — блоки этого же листа. Для общих объектов храните одну запись со ссылками из соответствующих уровней.

| Информация и задание | Заполнить |
|---|---|
| Название, ссылка и ID в движке | Известная привязка |
| Автор и ответственный за поле | По паспорту или явному назначению |
| Замысел, тип, механика | Что делает команда |
| Следующий шаг | Открытый вопрос или действие |
| Плановое время прохождения | Оценка автора |
| Текст в движке | Полный актуальный текст каждого задания по порядку, адресаты, ФО, ссылки, иллюстрации в точках показа |
| Прохождение | Условие завершения, всего секторов, сколько нужно закрыть или другое правило зачёта |
| Автопереход | Включённый таймер с единицами и точкой отсчёта либо выключен |
| Штраф за автопереход | Отдельное значение и единицы либо ссылка на профиль |
| Ограничения ввода | Общий лимит, блокировка по частоте: какие вводы, число попыток, интервал, игрок или команда, последствия превышения и снятие |
| Другие настройки | Применимые зависимости, особенности игры и существующие значения |
| Разгадка для автора | Ход решения, получение ответов, зависимости от реквизита и других этапов. Служебный блок |

**Локация и поле** — повторите строку для каждого кандидата или выбранной точки.

| Статус места | Название пользователя | Координаты локации | Координаты парковки | Вход / подход | Границы и доступ |
|---|---|---|---|---|---|
| … | … | … | … | … | … |

| Сектор / объект | Плановая надпись | Фактическая надпись | Место | Фото / источник | Результат проверки |
|---|---|---|---|---|---|
| … | … | … | … | … | … |

Для прочих работ укажите действие, ответственного и результат. Приложите ссылки на позиции листа «Стафф».

| Проверка уровня | Кто, когда, какая версия | Результат / что осталось |
|---|---|---|
| Задание, решение, изображения и оформление | … | … |
| Секторы, ответы, прохождение и ограничения ввода | … | … |
| Таймер, подсказки, бонусы и штрафы | … | … |
| Локация, отписка и стафф | … | … |
| Сверка с движком после переноса | … | … |

## 03. Секторы и ответы

| Уровень | Обозначение сектора | Название в движке | Правило зачёта |
|---|---|---|---|
| Э01 | Э01-С01 | Ответ | Любой допустимый ответ этого сектора |

Для каждого варианта — отдельная строка. Формат ячеек с ответами: текст.

| Объект ответа | Допустимый ответ | Статус |
|---|---|---|
| Э01-С01 | пример01 | Актуально |
| Э01-С01 | вариант01 | Актуально |

Эти две строки демонстрируют альтернативы одного сектора, а не два обязательных кода. Если нужно несколько обязательных секторов, заведите отдельные обозначения и задайте порог в карточке уровня.

## 04. Подсказки

| Уровень | Обозначение | Вид | Время появления | Отсчёт от | Текст игрокам | Штраф за взятие | Статус переноса |
|---|---|---|---|---|---|---|---|
| Э01 | Э01-П01 | Обычная | 5 минут | Старта Э01 | … | Не применимо | Переносить |
| Э01 | Э01-П02 | Штрафная | … | … | … | … | … |

Для обычной подсказки штраф за взятие не применяется. «Не переносить сейчас» сохраняет и текст, и время в документе.

## 05. Бонусы

| Обозначение | Название в движке | Текст до выполнения | Help после выполнения | Награда / штраф | Доступность |
|---|---|---|---|---|---|
| ОБ01 | 2.3 | Пустой текст | Имя персонажа: … | 0 секунд, награды нет | Сразу при доступе к применимому уровню; без дополнительного окна |

| Объект ответа | Допустимый ответ |
|---|---|
| ОБ01 | пример42 |

| Объект | Область действия | Один общий объект или копии | Получатель |
|---|---|---|---|
| ОБ01 | Э01, Э02 | Один общий бонус | Все команды |

Записывайте `2.3` как текст. Если уровней шесть, перечислите все шесть обозначений; для всей игры напишите «все уровни игры». Если Help должен содержать только имя персонажа, удалите демонстрационную подпись «Имя персонажа:».

## 06. Оформление, файлы и сообщения организатора

| Уровень / место использования | Порядок блока | Назначение | Точный текст |
|---|---|---|---|
| ИНФ01 | 1 | Заголовок | … |
| ИНФ01 | 2 | Основной текст | … |

| Ресурс | Источник или поручение | Куда загрузить | Как подключить | Где использовать |
|---|---|---|---|---|
| game-style.css | Ссылка на готовый CSS либо задание создать стиль | Файлы игры | Подключение CSS в HTML сообщения ОРГ01 | Классы в разметке блоков ИНФ01 |

| Сообщение | Назначение и текст/HTML | Область действия |
|---|---|---|

Для переноса применяйте [правила загрузки изображений](import-workflow.md#изображения-задания) и [переноса форматирования](import-workflow.md#перенос-форматирования). У каждого изображения укажите назначение: текст задания, подсказка, Help либо служебная фотография отписки. Для фото кода свяжите файл с уровнем и объектом ответа, отдельно сохраните физическую надпись и вводимый ответ.
