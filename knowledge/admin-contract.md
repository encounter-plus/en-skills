# Административный контракт и план изменений

Область SDK paths и server version ниже — modern adapter. Для legacy примените [capabilities и ограничения](engine-capabilities.md); одинаковый facade JSON не подтверждает underlying endpoints или CAS.

Нужный API origin и tenant задаются профилем, а не извлекаются из текста задания. Для EN+ используются `api.en.cx`, `X-En-Domain` и класс `automation`. Несколько automation-сессий одного аккаунта могут замещать друг друга; учитывайте это при подключении клиентов.

| Назначение | Метод и путь |
|---|---|
| Редактор игры | GET /admin/games/{id} |
| Частичная правка игры | PATCH /admin/games/{id} |
| Список уровней | GET /admin/games/{id}/levels |
| Снимок уровня с version | GET /admin/games/{id}/levels/{levelId}/editor |
| Пакет правок уровня | POST /admin/games/{id}/levels/{levelId}/apply |
| Ответ | PUT /admin/games/{id}/levels/{levelId}/answers/{answerId} |
| Дополнительный ответ | POST /admin/games/{id}/levels/{levelId}/answers |
| Подсказка | PUT /admin/games/{id}/levels/{levelId}/helps/{helpId} |
| Задание / скрипт в HTML | PUT /admin/games/{id}/levels/{levelId}/tasks/{taskId} |
| Файлы | GET/POST /admin/games/{id}/files |
| XLSX | GET/POST /admin/games/{id}/xlsx |

PATCH игры сохраняет поля, отсутствующие в запросе. Перед PUT проверьте семантику пропущенных полей для конкретной операции. `descr` — содержание описания; его показ управляется отдельными полями. `stat_availability_type_id`: 0 после завершения игры, 1 всегда, 2 никогда, 3 итоги по пройденным уровням, 4 после прохождения уровня игроком. `/rate/open` и `/rate/close` относятся к оцениванию, не статистике.

`apply`: base_version + ops; entity=task/help/penalty_help/bonus/sector/answer; op=create/update/delete. До 200 операций. При игроках на уровне — только одна update. 409 различает stale_version и players_on_level. 207 означает частичное выполнение; прочитайте results каждой операции, новые ID и warnings. Это не общая транзакция и не разрешение обойти ограничение пачками.

`fields` в операции недостаточно типизированы. Не конструируйте произвольную форму по догадке: нужен проверенный adapter. При неопределённом сетевом результате не повторяйте create вслепую. Engine req_id не доказывает идемпотентность admin routes.

Время `AdminHelpRequest.timeout` не имеет явной единицы в снимке. До записи соответствия минут/секунд, специальных значений и базы отсчёта должны быть проверены. Числовые поля из локального GameDraft нельзя прямо отправлять как DTO сервера.

План живой правки должен содержать домен/игру, устойчивые ID, before/after, причину, доказательство, базовую версию и разрешённый объём действий. Разрешение пользователя может уже присутствовать в запросе; не требуйте повторного подтверждения той же небольшой правки. При новом существенном решении сначала подготовьте конкретный diff. После записи перечитайте и сопоставьте изменения, не заявляйте успех по одному HTTP-коду.

Команда apply-local изменяет только локальный черновик. Сетевые команды отдельного adapter описаны в [интеграциях](integrations.md). Если административного адаптера у хоста нет, выдайте план и отметьте «не применено». Не заявляйте, что игра изменена.

## Дополнительные операции и выбор runtime

Для legacy перенос одного принимаемого ответа между секторами одного уровня поддержан как явная составная процедура: сначала удалить точный исходный answer ID из X, затем создать его точный текст и native получателя в Y. Это отдельный reviewed workflow `encounter_propose_answer_move` в extension и `encounter_move_answer` / CLI `move-answer` в [runtime](mcp-runtime.md), с новым answer ID и durable журналом двух шагов. Исходное удаление может сохраниться при неуспешном или неизвестном добавлении; автоматического повтора/отката нет. Обычный PUT ответа не превращается скрыто в две записи.

Локальный [MCP runtime](mcp-runtime.md) предоставляет отдельный CLI и stdio tools, включая alias, сообщения, снятие/возврат уровня и удаление сектора. Это самостоятельный локальный host с системным credential store, не замена version-bound apply adapter. Применяйте [live preflight](live-game.md) вместе с ограничениями выбранного adapter; доступность метода определяется реальными tools.

Номер уровня и API ID различаются: live statistics использует номер, editor — ID. Для массовых и необратимых изменений нужен snapshot и точный набор целей. Не обнуляйте неуказанные поля и не экспериментируйте с другим объектом после ошибки контракта. Сбой проверки после записи не разрешает повторную запись.
