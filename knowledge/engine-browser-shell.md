# Ресурсы оформления браузерного Encounter

Сохранённые CSS используются как ресурсы локального анонса. Неиспользуемые исторические HTML-оболочки удалены. Они не запускают runtime Encounter. Engine-профиль с адаптером EN+ удалён; маршрута /engine?layout=mobile больше нет.

Для проверки задания используйте [настоящую /preview Encounter](script-harness.md#настоящий-modern-js-runtime-encounter-через-preview), для EN+ — отдельный тестовый bridge из того же справочника. Успешный просмотр сохранённой оболочки не подтверждает выполнение API, серверные ответы или работу текущего сайта.

## Сохранённые ресурсы npm-пакета

- `harness/engine/style-0.css` и `style-1.css` — стили с локальными адресами ресурсов.
- `harness/engine/assets/` — шрифты и изображения оформления.
- `harness/engine/manifest.json` — происхождение ресурсов и границы локального оформления.

Отдельно установленный каталог скилла эти runtime assets не предоставляет. Перечень описывает npm-пакет, а не дополнительные файлы скилла.

## Разметка автора

Задание вставляется внутрь `.en-user-html`, а не вместо всей страницы. Ограничивайте CSS собственным контейнером. Публичные селекторы и API определены в [контракте задания](engine-task-contract.md); остальные классы и порядок узлов исторического снимка не являются гарантией текущего сайта.

Синтетические fixtures не проверяют настоящую авторизацию, WebSocket, ограничения попыток, native input или Android WebView. Отмечайте проверенный клиент и сценарий отдельно от непроверенных сред.
