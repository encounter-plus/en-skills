# Modern browser gameplay

Применяется только к modern gameplay. Прочитайте [точный EN контракт](../engine-task-contract.md) и [ограничения](../scripting-contract.md). Подтвердите используемые методы, события, поля и nullable verdict. Серверное время используйте по контракту; не выводите его из часов устройства. jQuery не предполагается встроенной. Контроллер live preview сохраняет строгую modern URL/state/window.EN проверку. Отсутствие API означает ошибку проверки, а не переключение на legacy.
