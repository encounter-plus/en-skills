# Общие правила авторского скрипта

Получите от host engine, surface и runtimeProfile. demo.en.cx использует modern + Kotlin; остальные разрешённые Encounter domains — legacy + RN. Произвольный URL не считается Encounter. При неизвестной цели подготовьте независимую механику и запросите цель до интеграции.

Для нового кода задания и анонса используйте современный JavaScript: const/let, native DOM querySelector/querySelectorAll и addEventListener, ограничивая selectors и обработчики собственным root. Legacy обозначает контракт движка, а не требование ES5. Наличие jQuery 1.6.2 в подтверждённом runtime — возможность подключить готовый внешний скрипт, а не основной стиль нового кода; такой скрипт сохраняйте без автоматической переписки, проверив зависимости на целевой поверхности.

Сохраняйте буквальный HTML и строки ответов. Инициализация идемпотентна; удаляйте старые subscriptions и timers. Храните durable состояние с origin/game/level ключами; closure может исчезнуть после rebuild. Административные credentials в авторском коде отсутствуют. Публикация через admin workflow отделена от player actions.

Gameplay и announcement — разные поверхности. Доступность API gameplay в анонсе не предполагается. Отдайте артефакт, место вставки, зависимости и фактические проверки с ограничениями.
