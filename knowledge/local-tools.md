# Локальные инструменты en-skills

CLI `en-author` доступен при установленном пакете @encounter-author/tools и Node.js 24+. Каталог установленного SKILL.md сам по себе не содержит runtime. Проверьте наличие команды в среде хоста. В отсутствие CLI выполните смысловую проверку доступными средствами и отметьте непроведённые механические проверки.

Команды установленного CLI:

```text
en-author validate --input game.json
en-author audit --input game.json
en-author checklist --format virtual
en-author photo-compare --input game.json --observations observations.json
en-author code-variants --code конь6
en-author apply-local --input game.json --plan plan.json --out revised.json
```

CLI читает нормализованный GameDraft, не произвольный ответ API. Полная структура и синтетические примеры доступны в [контракте локальных данных](local-data-contract.md). Все длительности модели явно в секундах; `null` означает отсутствие автоперехода или неизвестный ФО; пропущенное обязательное поле — ошибка. `requiredSectors: null` в этой ограниченной модели означает все секторы. Не переводите неизвестное условие сервера в null: оставьте его для уточнения перед преобразованием в GameDraft.

`audit` выполняет только механические проверки пустого задания, отсутствующего выделенного ФО, достижимости подсказок, числа секторов и точных дублей. Он не доказывает качество игры. `checklist` выдаёт все пункты каталога с исходным статусом `not-checked`; чисто полевые пункты виртуальной игры отмечаются `not-applicable`. Применимость остальных определяет проверяющий.

`photo-compare` НЕ читает изображения: он сравнивает уже полученные наблюдения с ответами. Каждое наблюдение содержит ID фото, domain/gameId/levelId/sectorId, reading (`clear`, `ambiguous`, `unreadable`), transcription, alternatives, mappingVerified, currentMarkingVerified и documentCode. Образец включён в [контракт локальных данных](local-data-contract.md#наблюдения-по-фото). Документное значение используется для отчёта, не для выбора чтения.

`code-variants` предлагает ограниченный список односимвольных визуальных гипотез, в том числе `конь6` → `кон66`. Это не OCR и не список автоматически принимаемых ответов. Даже при точном совпадении на фото можно предложить дополнительное правдоподобное чтение, но только с объяснением и проверкой влияния на механику.

`apply-local` применяет только текст задания и ФО к новому локальному файлу черновика. Требует точного `before`, совпадения игры/домена и `playersStarted: false`; существующий выходной файл не перезаписывает. Это не административная запись и не полная модель импорта. План содержит schemaVersion=1, mode=local-draft, gameId, domain и edits с levelId, field, before, after, reason.

Exit codes: 0 — команда выполнена; 1 — ошибка входных данных/IO; 2 — аудит нашёл ошибки. stdout — JSON результата (кроме --help); stderr — JSON ошибки.

Сетевые снимки, Google OAuth и OCR описаны в [интеграциях](integrations.md). Локальные команды выше не выполняют серверных записей; библиотечный applyLevel — отдельный явный метод. Telegram runtime, DOCX/XLSX parser и полный импорт не входят в пакет.
