# Учебная игра «Маяк»

Автор по умолчанию — Маша. В авторской таблице «Копилка» записаны «Эхо» (Саша) и «Зеркало» (Маша). Сводка называется «Маршрут». Лист «2. Башня» привязан к ID 830 и папке levels/level1. После перестановки название в движке — «1. Башня», ID 830.

Выбрана точка 55.7000, 37.5000 без названия, парковка совпадает. Для «Эха» есть два кандидата: «Двор» (55.7100, 37.5100) и 55.7200, 37.5200. Их парковки ещё не определены.

Учёт раздатки уже ведётся на листе «Реквизит». Нужно 10 комплектов. Саша собрал четыре закрытых конверта из десяти. На брифе каждой команде выдают один конверт. Карту выдадут у башни, конверт и карту используют на следующем уровне.

В условии «Башни» карта нужна игрокам после первого абзаца. Следом идут две колонки букв: позиции и красные буквы задают решение. Жёлтый фон заголовка листа — пометка редактора. Схема решения предназначена для подсказки через 8 минут от старта уровня. Фото отписки из внешней папки нужны авторам.
