# Генерация кодов Encounter

Перед генерацией прочитайте [параметры генераторов и правила античита](../../knowledge/code-generation.md). Этот справочник задаёт значения по умолчанию, ограничения, сохранение нулей и границы уникальности.

1. Определите режим по запросу: слово с античитом, буквы с античитом или цифры. Извлеките количество и ограничения автора; для пропущенных параметров используйте значения справочника. Если режим неоднозначен, уточните его перед вызовом.
2. Проверьте доступность соответствующего инструмента хоста: `generate_word_codes`, `generate_letter_codes` или `generate_digit_codes`. Установка скилла не добавляет эти инструменты или словарь. Если инструмент недоступен, перечислите подготовленные параметры и недостающую возможность; не выдавайте придуманный список за случайную генерацию.
3. Выполните генерацию с выбранными параметрами. Для слов используйте словарь существительных CityProject через инструмент. Если вариантов недостаточно, сообщите доступное количество и предложите конкретное изменение ограничений; применяйте его только после выбора автора.
4. По результату инструмента проверьте количество, соблюдение параметров и отсутствие повторов основ внутри выдачи. Для последовательных античитов проверьте полный запрошенный ряд и формат ведущих нулей; случайный диапазон не заменяет последовательность. При ошибке сообщите причину без вымышленного результата. При объединении нескольких выдач отдельно проверьте повторы: гарантия одной выдачи на них не распространяется.
5. Покажите применённые параметры и коды по одному на строку в текстовом блоке, если автор не запросил другой формат. Сохраняйте итоговые строки буквально, включая ведущие нули; при табличном выводе храните их как текст. Отметьте ограничения проверки, если они остались.

Результат — набор кандидатов для автора. Генерация завершается выдачей кодов или точным объяснением, почему их получить не удалось. Перенос выбранных кодов в игру — отдельный процесс `game-admin` с доступными инструментами и режимом доступа хоста.
