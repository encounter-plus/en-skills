# level-script: Создать интерактивное задание

## Когда применять

Создать интерактивное задание. Вызовите skill явно или опишите задачу обычными словами.

## Что передать

Механика и целевые клиенты EN+. Для скрипта страницы анонса используйте game-announcement.

## Что получится

HTML/JS, зависимости и воспроизводимый сценарий проверки.

## Как проверить результат

Артефакт проверен в доступных средах; Chromium не выдаётся за проверку устройства Android.

## Инструменты и согласование

Нужны доступные инструменты preview. Публикация в игру является отдельной разрешённой операцией.
