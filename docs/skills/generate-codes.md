# generate-codes: Получить коды с заданными ограничениями

## Когда применять

Получить коды с заданными ограничениями. Вызовите skill явно или опишите задачу обычными словами.

## Что передать

Режим, количество, ограничения; пропуски обрабатываются по правилам генератора.

## Что получится

Фактическая выдача инструмента и использованные параметры. Например: цифровые строки с ведущими нулями.

## Как проверить результат

Количество и ограничения проверены, строки сохранены буквально.

## Инструменты и согласование

Host предоставляет генератор и словарь для слов. Генерация не записывает коды в игру.
