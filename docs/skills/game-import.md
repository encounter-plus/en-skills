# game-import: Перенести готовые материалы в игру

## Когда применять

Перенести готовые материалы в игру. Вызовите skill явно или опишите задачу обычными словами.

## Что передать

Источник и объём переноса; для разработки идеи используйте level-author.

## Что получится

Сопоставление исходника с объектами, план и сводка сверенных результатов. Например: два уровня перенесены, вложение осталось неподдержанным.

## Как проверить результат

Все выбранные блоки учтены; частичный перенос не называется полным.

## Инструменты и согласование

Чтение и запись требуют инструментов host. Применяется конкретный разрешённый план с повторной сверкой.
