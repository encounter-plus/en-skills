# game-admin: Внести точечные изменения игры

## Когда применять

Внести точечные изменения игры. Вызовите skill явно или опишите задачу обычными словами.

## Что передать

Игра, объект и конкретное изменение. Массовый перенос готового документа относится к game-import.

## Что получится

План до/после и проверенные результаты операций.

## Как проверить результат

Изменены только разрешённые поля; неопределённая запись сверяется перед повтором.

## Инструменты и согласование

Нужен авторизованный adapter. Уже достаточное разрешение не спрашивается повторно; существенные неизвестные уточняются.
