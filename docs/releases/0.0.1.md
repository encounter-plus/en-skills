# en-skills 0.0.1

Первый выпуск набора скиллов для авторов игр Encounter — «Схватки» и «Точек».

## Возможности

12 скиллов: `game-author`, `level-author`, `travel-levels`, `generate-codes`, `game-announcement`, `game-audit`, `check-code-photos`, `game-import`, `game-admin`, `game-recalculation`, `level-script`, `google-documents`.

Набор помогает пройти от замысла и подготовки сценария до проверки материалов и согласованного переноса в движок. Включает правила сохранения кодов без нормализации, разделения фото-свидетельств и принятых ответов, проверки авторского замысла, планирования импорта и подтверждения изменений. Каждый собранный скилл содержит собственные справочники и необходимые скрипты.

Скиллы задают процесс работы ассистента. Браузер, авторизация, инструменты записи в Encounter и обработки изображений предоставляются приложением пользователя. ZIP не устанавливает CLI, MCP runtime или аккаунты.

## Установка

Скачайте `en-skills-0.0.1.zip` и `en-skills-0.0.1.zip.sha256` из вложений выпуска, проверьте SHA-256, распакуйте архив и установите целые папки скиллов по [инструкции](https://github.com/encounter-plus/en-skills/blob/HEAD/docs/install.md). Для готового ZIP сборка через npm не требуется. Node.js 24+ нужен для сборки из исходников и инструментов npm-пакета; выполнение отдельных скриптов зависит от окружения приложения.

Автоматический GitHub архив **Source code** содержит исходники, а не готовый набор для копирования. Установка из npm registry не предусмотрена: пакет имеет `private: true`.

## Проверки и границы

Оба профиля снимков WebView используют `schemaVersion: 1`. Справочники в ZIP соответствуют этой схеме; сами снимки и CLI поставляются в npm-пакете для интеграций.

Проверки типов, 354 теста, сборка и валидация скиллов, ссылок, каталога маршрутизации и eval-сценариев пройдены. Автономный npm-пакет проверен в чистом временном проекте: импорты, типы потребителя, CLI, 12 скиллов и 98 правил. Все 462 файла ZIP сверены со сборкой по SHA-256; ссылки в 457 Markdown-файлах проверены после распаковки.

При разработке проведены A/B-проверки поведения агента, проверки реальных фотографий, desktop/mobile browser preview, Legacy-импорта и чтения сохранённых данных. Полный A/B охватывал 390 запусков; после последней точечной правки выполнены девять успешных проверок, без повторения полной выборки. Оценки A/B получены моделью; статистическая значимость и экономия токенов не заявляются.

Не подтверждены этими результатами: полноценное накопленное командное прохождение, Android-устройство и Modern/Kotlin end-to-end, браузерная запись Google Docs/Sheets и end-to-end выполнение перерасчёта. Успешный локальный RN preview использовал заменители изображений; он не закрывает CSP-ошибки внешних изображений первоначального изолированного стенда. Спорные фото требуют авторской проверки, а не автоматической замены ответов.
